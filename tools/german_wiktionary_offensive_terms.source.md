# German blocklist source

This reviewable source list was collected from Wiktionary on 2026-10-01 via the MediaWiki API. It contains the union of the page members of:

- https://en.wiktionary.org/wiki/Category:German_offensive_terms (139 direct entries)
- https://en.wiktionary.org/wiki/Category:German_ethnic_slurs (34 entries)
- https://en.wiktionary.org/wiki/Category:German_religious_slurs (1 entry)

The combined list has 158 distinct page titles. The category membership is a source signal, not a claim that every term is offensive in every context; review the list before shipping it to a particular moderation policy. The input is intentionally kept in cleartext for review. `tools/generate_blocklist.py` emits only hashes for runtime use.
