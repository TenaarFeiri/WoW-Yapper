===========================================================================
    Yapper Public API  (Src/API.lua)
===========================================================================
    This file documents the public object exposed as `_G.YapperAPI`.
    The Markdown reference is available at:
    https://github.com/TenaarFeiri/WoW-Yapper/tree/main/Documentation

    YapperAPI is the supported integration surface for other addons.  It
    lets an addon register filters and callbacks, inspect Yapper state, and
    use selected UI and spellcheck services without reaching into the
    internal YapperTable.

    API compatibility is feature-detected.  Addons should not branch on an
    API version number; use the documented methods and grouped aliases.

    Filters and callbacks are sandboxed with pcall().  A handler error does
    not propagate into Yapper's runtime; it is reported through API_ERROR or,
    when no API_ERROR handler is registered, through debug output.

---------------------------------------------------------------------------
1. FILTERS (pre-hooks)
---------------------------------------------------------------------------

    Filters run before an operation.  They receive one payload table and may
    return a replacement payload table, return false to cancel, or return nil
    to leave the current payload unchanged.  The normal convention is to
    mutate the received table and return it.

    local handle = YapperAPI:RegisterFilter(hookPoint, callback, priority)
    YapperAPI:UnregisterFilter(handle)

    hookPoint   string; one of the hook points below.
    callback    function(payload) returning table, false, or nil.
    priority    optional number; lower values run first, default 10.  Ties
                run in registration/handle order.
    handle      number, or nil when the arguments are invalid or the per-hook
                registration cap (50) has been reached.

    Unknown filter names are rejected.  There are currently no filter aliases.
    Each hook point accepts at most 50 registered filters.

    PRE_EDITBOX_SHOW
      Payload: { chatType, target }
      Cancellable: yes.
      Runs before the Yapper overlay opens.  Return false to suppress the
      overlay.  chatType and target may be nil.

    PRE_EDITBOX_LABEL
      Payload: { chatType, target, channelName, label, unit }
      Cancellable: no.
      Runs while Yapper resolves the overlay label.  Mutate label to provide
      custom text.  Returning false is ignored and normal label resolution
      remains in place.  Yapper deep-copies the original payload and restores
      it if the filter returns false or malformed values.

    PRE_MULTILINE_SHOW
      Payload: { text, chatType, language, target }
      Cancellable: yes.
      Runs before the expanded multiline editor opens.  Modify the initial
      text or routing fields, or return false to block opening.

    PRE_SEND
      Payload: { text, chatType, language, target }
      Cancellable: yes.
      Runs once for each composed send, before chunking and after the original
      text has been recorded to chat history.  text may contain newlines;
      Yapper treats each resulting line as a separate post.  Filters may
      rewrite text, chatType, language, or target, or return false to cancel.

    PRE_CHUNK
      Payload: { text, limit, chatType, language }
      Cancellable: yes.
      Runs once for each contiguous text unit passed to the chunker, including
      text that is already shorter than the limit.  Filters may rewrite text
      or limit, or set these optional fields:

        continuationPrefix       string; prepend to chunks after the first.
        continuationPrefixFirst  boolean; when true, put the continuation
                                  prefix before the delineator instead of after
                                  it.

      The continuation prefix is included in the byte budget automatically.
      Return false to make chunking return nil and abort that send.

    PRE_SPELLCHECK
      Payload: { text }
      Cancellable: yes.
      Runs before spellcheck examines the text.  Return false to skip that
      spellcheck operation.

    PRE_SPELLCHECK_SUGGESTIONS
      Payload: { word, suggestions, locale }
      Cancellable: yes.
      Runs after suggestions have been scored, sorted, and formatted, but
      before they are cached and shown.  Mutate, reorder, add, remove, or
      replace the suggestions array, then return the payload.  Return false to
      suppress the suggestion result.

      Suggestion entries normally have one of these forms:
        { kind="word",   value=string, score=number, baseScore=number }
        { kind="add",    value=string }
        { kind="ignore", value=string }
        { kind="split",  value=string }

      Call YapperAPI:ClearSuggestionCache() after changing plugin state if a
      previously cached result must be recomputed.

    PRE_DELIVER
      Payload: { text, chatType, language, target }
      Cancellable: yes, with delegation semantics.
      Runs immediately before Yapper hands one message to its router.  Return
      false to claim the message.  Yapper then emits POST_CLAIMED with a
      delegation handle and starts a five-second timeout.  The claiming addon
      must call YapperAPI:ResolvePost(handle) before the timeout.  If it does
      not, Yapper sends the message itself and reports the responsible owner.

    PRE_ICON_GALLERY_SHOW
      Payload: { rawEditBox, query }
      Cancellable: yes.
      Runs before the raid-icon gallery opens.  Filters may rewrite both the
      editbox and query, or return false to suppress the gallery.

---------------------------------------------------------------------------
2. CALLBACKS (post-hooks / notifications)
---------------------------------------------------------------------------

    Callbacks are notification-only.  Their return values are ignored.

    local handle = YapperAPI:RegisterCallback(event, callback)
    YapperAPI:UnregisterCallback(handle)

    event       string; one of the events below.
    callback    function called with the event-specific arguments.
    handle      number, or nil when the arguments are invalid or the per-event
                registration cap (50) has been reached.

    Unknown event names are rejected.  Each event accepts at most 50
    registered callbacks.  The deprecated YALLM_WORD_LEARNED name is accepted
    and resolves to YAS_WORD_LEARNED.

    POST_SEND(text, chatType, language, target)
      Fires after the message has been handed to the router or WoW chat send
      API successfully.

    POST_CLAIMED(handle, text, chatType, language, target)
      Fires when PRE_DELIVER returns false and Yapper creates a delegation
      claim.  Resolve the handle with ResolvePost() after the claiming addon
      has delivered the message.

    CONFIG_CHANGED(path, value)
      Fires when a Yapper setting changes.  path is a dot-delimited config
      path such as "EditBox.FontSize" or "Spellcheck.Locale".

    STATE_CHANGED(newState, oldState, ...)
      Fires after a state-machine transition.  The trailing values are the
      metadata supplied to SetState or the internal transition.  Current state
      names are INITIALISING, IDLE, EDITING, MULTILINE, SENDING, STALLED,
      LOCKDOWN, and CONFIG.

    EDITBOX_SHOW(chatType, target)
      Fires when the Yapper overlay becomes visible.

    EDITBOX_HIDE()
      Fires when the Yapper overlay is hidden.

    EDITBOX_TEXT_CHANGED(text, isUserInput, box)
      Fires when an editbox's text changes.  box is the relevant WoW EditBox
      frame; text is Yapper's canonical text representation.

    EDITBOX_CHANNEL_CHANGED(chatType, target)
      Fires when the active chat channel or target changes.

    EDITBOX_LABEL_UPDATED(label, r, g, b)
      Fires after the visible channel label and its text colour are refreshed.

    THEME_CHANGED(themeName)
      Fires after the active theme changes through the theme API or a live
      theme update.

    SPELLCHECK_SUGGESTION(word, suggestions)
      Fires when a suggestion popup is shown.  suggestions is the displayed
      suggestion list (an array of strings in the public callback).

    SPELLCHECK_SUGGESTION_HIGHLIGHTED(text, index, total)
      Fires when a suggestion is highlighted.  text is the colour-code-free
      display text, index is one-based, and total is the number of suggestions.

    SPELLCHECK_APPLIED(original, replacement)
      Fires when a suggestion is applied to the editbox.

    SPELLCHECK_CLOSED()
      Fires when the suggestion popup closes.

    SPELLCHECK_WORD_ADDED(word, locale)
      Fires when a word is added to the current user dictionary, manually or
      through Yapper's adaptive system.

    SPELLCHECK_WORD_IGNORED(word, locale)
      Fires when a word is marked as ignored.

    YALLM_WORD_LEARNED(word, locale)  [DEPRECATED]
      Backward-compatible alias for YAS_WORD_LEARNED.  New registrations
      should use YAS_WORD_LEARNED.

    YAS_WORD_LEARNED(word, locale)
      Fires when YAS automatically promotes a word to the user dictionary.

    QUEUE_STALL(chatType, policyClass, chunksRemaining)
      Fires when the delivery queue's acknowledgement timer expires and a
      Continue prompt is shown.  chunksRemaining includes the stalled chunk.

    QUEUE_COMPLETE()
      Fires when the delivery queue finishes or is cancelled.

    ICON_GALLERY_SHOW(query)
      Fires when the raid-icon gallery opens.  query is the text after the
      opening brace and may be empty.

    ICON_GALLERY_HIDE()
      Fires when the raid-icon gallery closes.

    ICON_GALLERY_SELECT(index, text, code)
      Fires when the user selects an icon.  index is 1-8, text is the icon
      name (for example "skull"), and code is its shorthand (for example
      "rt8").

    API_ERROR(kind, hook, handler_info, errorMessage, data, ...)
      Fires when an external handler errors, returns an unexpected filter
      value, or an API operation reports an error.  handler_info is nil when
      no handler caused the error; otherwise it is a table containing:

        handle    registration handle
        priority  filter priority, when applicable
        owner     best-effort addon/source owner, when available

      data is the relevant payload or returned value and the trailing values
      are the original callback arguments when applicable.  kind commonly
      includes "filter", "callback", and "filter-return", but operation-level
      errors may use more specific values such as "SETTINGS" or
      "delegation-timeout".

      Ownership routing is best effort.  Yapper first sends the error to
      API_ERROR handlers registered by the same detected addon/source owner as
      the failing handler.  If none exist, it broadcasts to all API_ERROR
      handlers.  If no API_ERROR handler exists, Yapper writes debug output.

---------------------------------------------------------------------------
3. ACCESSORS AND STATE
---------------------------------------------------------------------------

    YapperAPI:GetVersion() → string
      Returns the addon metadata version, or "unknown" if the core is not
      available. API compatibility should be feature-detected rather than
      inferred from this addon metadata.

    YapperAPI:GetCurrentTheme() → string|nil
      Returns the active theme name.

    YapperAPI:IsOverlayShown() → boolean
      Returns whether the single-line Yapper overlay is visible.

    YapperAPI:GetConfig(path) → any|nil
      Reads a value using a dot-delimited path, such as
      "Chat.DELINEATOR".  Tables are deep-copied before returning them.
      The deprecated path "Spellcheck.UnderlineColor" is accepted and maps to
      "Spellcheck.MisspellingColour" with a warning.

    YapperAPI:GetDelineator() → string|nil
      Returns the configured chat chunk delineator (DELINEATOR, falling back
      to the legacy PREFIX key).

    YapperAPI:GetState() → string
    YapperAPI:IsState(stateName) → boolean
    YapperAPI:GetStates() → string[]
      Returns the current state, tests a state, or returns all valid state
      names sorted alphabetically.  Valid names are INITIALISING, IDLE,
      EDITING, MULTILINE, SENDING, STALLED, LOCKDOWN, and CONFIG.

    YapperAPI:GetStateLogs() → table
    YapperAPI:GetStateLog(index) → table|nil
    YapperAPI:GetStateLogCount() → number
      Inspect the circular state-transition buffer, which holds at most 200
      entries.  Each entry has { time, old, new, file, func, line }.  The
      returned log table and individual entries are copied snapshots; they
      may be safely inspected or modified by the caller.

    YapperAPI:SetState(stateName, ...) → boolean  [DEPRECATED]
      Requests a transition to a valid state and returns true when the request
      was accepted.  The first use emits a deprecation warning and API_ERROR
      notification. Extra values are forwarded as STATE_CHANGED metadata.
      Invalid state names return false. Avoid new usage: forcing a state can
      bypass internal safety logic or desynchronise the UI.

    YapperAPI:ListFrames() → table
      Returns flat frame keys Overlay, OverlayEdit, LabelBg, SuggestionFrame,
      HintFrame, SuggestionClickCatcher, MultilineFrame, MultilineEdit, and
      MultilineScroll.  It also includes All, the categorized frame registry.
      The returned frame references and All registry are live objects; do not
      mutate the registry itself.

4. SPELLCHECK AND LANGUAGE REGISTRATION
---------------------------------------------------------------------------

    YapperAPI:IsSpellcheckEnabled() → boolean
    YapperAPI:CheckWord(word) → boolean
    YapperAPI:GetSuggestions(word) → string[]|nil
    YapperAPI:GetSpellcheckLocale() → string|nil
    YapperAPI:AddToDictionary(word) → boolean
    YapperAPI:IgnoreWord(word) → boolean
    YapperAPI:IsSuggestionOpen() → boolean
    YapperAPI:HideSuggestions() → boolean
    YapperAPI:ApplySuggestion(index) → boolean
    YapperAPI:FindMisspellings(text) → table[]|nil
    YapperAPI:ClearSuggestionCache() → boolean

      These are safe wrappers and return false or nil when spellcheck is not
      available or the arguments are invalid.  GetSuggestions returns public
      word strings rather than internal scoring records.  FindMisspellings
      returns nil when disabled, unavailable, or no misspellings are found;
      each result has { startPos, endPos, word }.  ApplySuggestion uses a
      one-based row index.  HideSuggestions reports whether the spellcheck
      service was available, not necessarily whether a visible popup existed.
      ClearSuggestionCache returns true when the cache was cleared.

    YapperAPI:RegisterDictionary(locale, data) → boolean
      Registers a dictionary table or a builder function for a locale.  A
      table may contain words, phonetics, extends, languageFamily, affixRules,
      and an optional embedded engine table.  Delta status is inferred from
      extends.  Every dictionary must resolve to a languageFamily (directly or
      via extends) whose engine is already registered; there is no implicit
      default family.  A function is stored as a lazy dictionary builder.  The
      call returns false for invalid arguments, unavailable spellcheck, or an
      error during dispatch.  A true return means dispatch completed without a
      Lua error; internal contract and security validation can still reject
      dictionary data.

    YapperAPI:RegisterLanguageEngine(familyId, engine) → boolean
      Registers a language engine for a locale family under a strict contract
      (see Documentation/Dictionaries.md for the full schema, limits, and
      failure semantics).  The engine table is deep-copied, validated
      (whitelist + type checks + runtime probes), and owner-locked: after a
      family is claimed by one addon, only that addon may re-register it.

      Required: NormaliseWord, NormaliseVowels, GetPhoneticHash, HashWord,
      BlockedHashes, WordBytes, WordStartBytes.
      Optional: StripAffixes, ShouldCheckWord, MatchCase, IsSaneWord,
      HasVariantRules, VariantRules, ScoreWeights, KBLayouts, DefaultLayout,
      Locales, DisplayName.  Unknown keys are rejected; engine-private fields
      must use an "X_" prefix.

      A runtime error inside engine code purges the engine and every
      dictionary bound to its family, and marks the affected locales
      ENGINE_PURGED.

    YapperAPI:IsLanguageEngineRegistered(familyId) → boolean
    YapperAPI:GetLanguageEngine(familyId) → table|nil
      Test for or retrieve a registered engine.  GetLanguageEngine returns a
      copy; nested tables are not live registry data.

    YapperAPI:RegisterLocaleAddon(locale, addonName) → boolean
      Associates a load-on-demand dictionary addon with a locale, for example
      "ptBR" and "Yapper_Dict_pt".  If that locale is active, Yapper attempts
      to ensure it immediately.

    YapperAPI:RegisterStrings(locale, strings) → boolean
      Registers a sparse UI-string table for a client locale (e.g. "deDE").
      Keys must exist in the canonical English table (Src/Strings.lua);
      missing keys fall back to English.  Owner-captured; re-registering
      replaces your addon's contribution wholesale and fires STRINGS_UPDATED.
      enUS is core-owned and cannot be overridden.

    YapperAPI:GetString(key, ...) → string
      Resolves a UI string for the active client locale with English
      fallback.  Extra arguments feed string.format.  Never returns nil —
      an unknown key resolves to the key itself.

---------------------------------------------------------------------------
5. CHAT, QUEUE, ATOMIC TEXT, AND DELEGATION
---------------------------------------------------------------------------

    YapperAPI:InsertText(text) → boolean
      Inserts non-empty text at the cursor in the active Yapper editbox.
      The multiline editor has priority over the single-line overlay.  Returns
      false for empty/non-string text or when no Yapper editbox is active.

    YapperAPI:GetQueueState() → table
      Returns a snapshot with active, stalled, chatType, policyClass, pending,
      and inFlight fields.  pending is the queued count and inFlight is 0 or
      1.  expectedAckEvent is intentionally removed from the returned
      snapshot because it is internal.

    YapperAPI:CancelQueue() → number
      Cancels the active queue and returns the number of discarded chunks.  It
      returns 0 when there is no queue to cancel and emits QUEUE_COMPLETE when
      an active queue is cancelled.

    YapperAPI:ResolvePost(handle) → boolean
      Resolves a handle received through POST_CLAIMED.  Returns true only when
      the active claim existed and was cleared before the five-second timeout.

    YapperAPI:RegisterAtomicPattern(pattern) → boolean
      Registers a non-empty Lua string pattern that chunking treats as an
      atomic token, useful for addon-injected pseudo-links.  Patterns are
      appended as supplied; duplicate patterns are allowed.

    YapperAPI:GetRegisteredAtomicPatterns() → string[]
      Returns a copy of the registered atomic patterns. Use
      RegisterAtomicPattern to add entries.

---------------------------------------------------------------------------
6. THEMES AND UTILITY HELPERS
---------------------------------------------------------------------------

    YapperAPI:RegisterTheme(name, data) → boolean
      Registers a named theme.  data is a table following the theme schema,
      including inputBg, labelBg, textColor, borderColor, border,
      allowRoundedCorners, allowDropShadow, font, and optional OnApply fields.
      The registry stores the supplied table; callers should not mutate it
      after registration.

    YapperAPI:SetTheme(name) → boolean
      Activates a registered theme, persists the selection, updates live UI,
      and emits THEME_CHANGED.  Returns false when the theme does not exist.

    YapperAPI:GetRegisteredThemes() → string[]
      Returns registered theme names sorted alphabetically.

    YapperAPI:GetTheme(name) → table|nil
      Returns a deep copy of a theme.  With no name or nil, returns a copy of
      the active theme.

    YapperAPI:IsChatLockdown() → boolean
      Returns whether WoW chat messaging is currently under lockdown.

    YapperAPI:IsSecret(value) → boolean
      Uses WoW secret/accessibility predicates when available, with a |K token
      and empty-string fallback heuristic.  It also treats nil and false as
      secret values.  Use this before logging or persisting untrusted WoW
      values.

    YapperAPI:Deleet(word) → string
      Converts common leetspeak substitutions (such as 4→a, 3→e, 1→i,
      0→o, 5→s, and 7→t) back to letters.

    YapperAPI:GetChatParent() → Frame
      Returns UIParent or the currently active fullscreen chat parent.

    YapperAPI:MakeFullscreenAware(frame) → nil
      Hooks a frame so it is reparented when the active fullscreen panel
      changes.  This is useful for addon UI that must remain visible over
      panels that hide UIParent.

    YapperAPI:OpenBlizzardChat() → nil
      Closes/hands off from Yapper to the original Blizzard chat editbox,
      equivalent to the Bypass Yapper keybind (Shift-Enter).  The underlying
      lifecycle also supports requesting the next chat open to bypass Yapper
      when no overlay is currently open.

---------------------------------------------------------------------------
7. ICON GALLERY
---------------------------------------------------------------------------

    YapperAPI:ShowIconGallery(editBox, anchorFrame, query) → nil
      Shows the raid-icon gallery for a raw WoW EditBox.  anchorFrame is the
      frame used for positioning and defaults to editBox.  query is optional
      and defaults to an empty string.  PRE_ICON_GALLERY_SHOW can rewrite the
      editbox and query or suppress the operation.

    YapperAPI:HideIconGallery() → nil
    YapperAPI:IsIconGalleryShown() → boolean
      Hide the gallery or test whether it is active.

    YapperAPI:GetRaidIconData() → table[]
      Returns eight newly-created metadata tables with index, text, and code
      fields.  The entries are star/rt1, circle/rt2, diamond/rt3,
      triangle/rt4, moon/rt5, square/rt6, cross/rt7, and skull/rt8.

---------------------------------------------------------------------------
8. AUTOCOMPLETE AND GHOST TEXT
---------------------------------------------------------------------------

    YapperAPI:GetAutocompleteSuggestion(word, prevWord) → string|nil
      Returns the best autocomplete result for a partial word, or nil when no
      result is available.  The autocomplete engine may require a minimum
      prefix length.  prevWord is optional: when given, learned bigram
      transitions (what the user habitually types after that word) weight the
      ranking; omitted, the sentence-initial context applies.

    YapperAPI:GetCaretOffset(editBox) → x, y, height
      Returns the caret position and height in logical pixels for a Yapper-
      managed or hooked EditBox.  Returns 0, 0, 0 when the editbox is not the
      currently hooked one.

    YapperAPI:GetGhostFrame() → FontString|nil
      Returns the shared ghost-text FontString, creating/reparenting it as
      needed for the active editbox.

    YapperAPI:ShowGhostText(text, editBox, prefix, textUpToCursor) → nil
      Manually shows ghost text on editBox.  prefix and textUpToCursor are
      optional; when omitted, the supplied text is treated as the ghost
      suffix for positioning.

    YapperAPI:HideGhostText() → nil
      Hides and clears the shared ghost text.

    YapperAPI:SetGhostTextOffset(offsetX, offsetY) → nil
      Sets a manual pixel offset for ghost-text positioning.

    YapperAPI:SyncGhostTextFont() → nil
      Synchronizes the ghost FontString font with its active parent EditBox.

    YapperAPI:SetSpellcheckTooltipOffset(hintX, hintY, suggestX, suggestY) → nil
      Sets manual pixel offsets for the spellcheck hint and suggestion
      tooltips.  Each argument is optional; omitted values retain the current
      offset.

---------------------------------------------------------------------------
9. SETTINGS CATEGORY INTEGRATION
---------------------------------------------------------------------------

    YapperAPI:RegisterSettingsCategory(id, label, options) → boolean
      Registers an addon settings category in Yapper's settings window.
      id and label must be non-empty strings.  options must be a table and
      normally supplies either:

        render(contentFrame, cursor)  custom renderer function
        schema                         schema rendered by Yapper
        internal = true                hide from GetRegisteredSettingsCategories

      Duplicate IDs and registrations beyond the total cap of 20 are rejected.
      The category is also rejected unless render, schema, or the internal
      implementation flag is present.

    YapperAPI:UnregisterSettingsCategory(id) → nil
      Removes a category with the matching ID.  Invalid or unknown IDs are
      ignored.

    YapperAPI:GetRegisteredSettingsCategories() → table[]
      Returns newly-created { id, label } tables for registered categories that
      are not marked internal.  The returned list is safe to modify.

    YapperAPI:OpenSettingsCategory(id) → boolean
      Opens Yapper's settings window and selects the requested category.
      Returns false for an invalid ID or when the Interface module is not
      available.  The method itself does not verify that the category exists.

10. NOTES FOR ADDON AUTHORS
---------------------------------------------------------------------------

    Grouped aliases are available for feature detection and organization.
    They reference the same flat methods and use colon-call syntax:

      YapperAPI.Filters     → RegisterFilter, UnregisterFilter
      YapperAPI.Callbacks   → RegisterCallback, UnregisterCallback
      YapperAPI.State       → state accessors and deprecated SetState
      YapperAPI.Chat        → chat, queue, delegation, and atomic-text methods
      YapperAPI.Spellcheck  → spellcheck and language registration methods
      YapperAPI.Themes      → theme methods
      YapperAPI.UI          → overlay, frames, gallery, ghost text, and UI methods
      YapperAPI.Settings    → settings-category methods
      YapperAPI.Utility     → config and utility methods

    • Do not depend on YapperTable or the internal API object.  Use the global
      YapperAPI methods documented here.

    • Unregister filters and callbacks when an integration is no longer
      needed.  Registration is capped at 50 handlers per hook/event.

    • GetStateLogs, GetStateLog, GetLanguageEngine, GetConfig,
      GetRegisteredAtomicPatterns, and GetTheme return copied data. ListFrames
      intentionally exposes live frame objects so addons can customize them;
      do not replace its registry structure.

    • Filter payloads are ordinary tables.  Mutate them in place and return
      the payload explicitly.  A nil return currently means continue unchanged
      for compatibility, but returning the table is the stable convention.

    • PRE_EDITBOX_LABEL is deliberately non-cancellable.  PRE_DELIVER is the
      only filter whose false result starts an external delivery delegation;
      always resolve its POST_CLAIMED handle promptly.

    • If a needed hook or accessor does not exist, open an issue or pull
      request on the Yapper repository rather than depending on internals.
